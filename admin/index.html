Falta configurar el panel

Abre admin.html en un editor y pega tus credenciales de Supabase en las dos primeras líneas del script:

  1. Entra a tu proyecto en supabase.com
  2. Ve a Settings → API
  3. Copia Project URL en SUPABASE_URL
  4. Copia la clave anon public en SUPABASE_ANON_KEY
  5. Guarda y recarga esta página

Antes de esto debes haber ejecutado supabase-schema.sql en el SQL Editor.
